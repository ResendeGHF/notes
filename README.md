# Notes (Saber Fork)

This repository contains a highly modified, experimental, and personal fork of [Saber](https://github.com/saber-notes/saber/), the open-source note-taking application originally created and maintained by **Adil Hanney** ([@adil192](https://github.com/adil192)).

This version diverges significantly from the upstream project. The codebase has been heavily modified and expanded to fit my specific academic workflow and daily tasks. I utilized AI (Gemini) throughout development; its primary contribution was generating code for a complete UI/UX redesign. I also leveraged it as a learning and assistive tool for minor tasks like debugging, documenting, troubleshooting, and suggesting algorithmic optimizations, which I then implemented manually. The application has been stripped down to support **Android exclusively**.
