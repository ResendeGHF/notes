# Notes (Saber Fork)

This repository contains a highly modified, experimental, and personal fork of [Saber](https://github.com/saber-notes/saber/), the open-source note-taking application originally created and maintained by **Adil Hanney** ([@adil192](https://github.com/adil192)).

This version diverges significantly from the upstream project. The codebase has been heavily modified and expanded to fit my specific academic workflow and daily tasks. Fundamentally, this fork served as a rewarding hobby project—a practical sandbox for me to study and implement complex algorithms, data structures, and performance optimizations. While it was built first and foremost as a continuous learning experience rather than a polished, consumer-ready product, I do rely on it daily as my primary note-taking application, and despite its experimental nature, it serves this purpose well. I utilized AI (Gemini) throughout development; its primary contribution was generating code for a complete UI/UX redesign. I also leveraged it as a learning and assistive tool for minor tasks like debugging, documenting, troubleshooting, and suggesting algorithmic optimizations. The application has been stripped down to support **Android exclusively**.

## ⚠️ Disclaimer: Experimental & Personal Use Only

If you have stumbled upon this repository, please be aware of the following:

* **This is experimental:** This project serves as a personal hobby project. It contains experimental, unpolished features and is constantly subject to breaking changes.
* **Not for Production:** This application is not intended for the general public. There are no guarantees regarding stability, data safety, or consistent behavior. 
* **Limited Scope:** This repository is public primarily to provide source code access to a specific group of university colleagues who are already familiar with the app's internal workings.
