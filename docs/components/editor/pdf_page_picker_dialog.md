## Documentation migrated from source

### Block 1

A professional, minimalist PDF page picker for importing selected pages
 as images into an infinite canvas note.

 Features a clean grid of page thumbnails with tap-to-select, optional
 select-all, and refined visual feedback.

### Block 2

Shows the dialog and returns the selected page indices (0-based).
 Returns null if cancelled.
